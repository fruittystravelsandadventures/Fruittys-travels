## Publish it free on GitHub Pages
1. Go to github.com and create a free account (if you don't have one).
2. Click the **+** in the top right → **New repository**. Name it `fruittys-travel` (or anything), keep it Public, click **Create repository**.
3. On the new repo page, click **uploading an existing file** and drag in `index.html` (and this `README.md` if you like). Commit the changes.
4. Go to the repo's **Settings** tab → **Pages** (left sidebar).
5. Under **Source**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`. Save.
6. Wait 1–2 minutes, then refresh — GitHub will show your live link, something like:
   `https://yourusername.github.io/fruittys-travel/`

That link is your free website. Every time you upload a changed `index.html` to the repo, the live site updates automatically within a minute or two.
